# OS Simulator

An interactive web-based simulator for exploring core **Operating System concepts** through visual and hands-on modules.

---

## Overview
The **OS Simulator** is designed to help students and beginners understand fundamental operating system concepts through interactive visualizations. Each module focuses on a specific topic, allowing users to experiment and learn intuitively.

---

## Modules Included

- **Process Scheduling**  
  Learn CPU scheduling algorithms like FCFS, SJF, Round Robin, etc.

- **MFT & MVT**  
  Understand fixed and variable memory partitioning.

- **Banker’s Algorithm**  
  Explore deadlock avoidance and detection techniques.

- **Fit Algorithms**  
  Simulate memory allocation strategies (First Fit, Best Fit, Worst Fit).

- **File Organization**  
  Visualize hierarchical (tree-based) file systems.

- **Resource Allocation Graph**  
  Detect and understand deadlocks using graphs.

- **Disk Scheduling**  
  Explore disk head scheduling algorithms like SSTF, SCAN, LOOK.

- **Page Replacement Algorithms**  
  Includes FIFO, LRU, LFU, MRU, Optimal, and Random.

- **System Calls**  
  Learn interaction between user programs and the OS kernel.

- **Inter-Process Communication**  
  Understand how processes communicate and share data.

- **Process Synchronization**  
  Learn concurrency control mechanisms.

- **File Allocation**  
  Explore different file allocation strategies.

- **LRU Approximation (Second Chance)**  
  Simulation of clock-based page replacement.

- **Firing Squad Problem**  
  Demonstrates synchronization in distributed systems.
