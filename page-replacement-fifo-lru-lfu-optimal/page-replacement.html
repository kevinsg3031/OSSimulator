Page Replacement Algorithms

Understanding Page Replacement

A Page Replacement Algorithm is a technique employed by the OS (Operating System) to manage memory by selecting which page to replace in the main memory when it becomes full. The primary goal is to minimize page faults and optimize system performance.

Key Concepts

  • Page Fault: ⚠️ The page requested is not in main memory, causing a slower access to secondary memory to fetch and load the page
  • Frame: 📦 A fixed-size physical memory block in main memory
  • Page: 📄 A fixed-size logical memory block in virtual memory
  • Miss: ❌ Page requested is not in memory
  • Hit: ✓ Page requested is already in memory

Available Algorithms

  • FIFO: The page which arrived first is replaced
  • Optimal: The page with the latest next occurrence is replaced (requires foreknowledge)
  • LRU: The page with the earliest last usage is replaced
  • MRU: The page with the latest last usage is replaced
  • LFU: The page with the minimum number of uses is replaced (FIFO as tie-breaker)
  • MFU: The page with the maximum number of uses is replaced (FIFO as tie-breaker)
  • Random: The page to replace is selected randomly
